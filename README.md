# JavaScript Coding Practice

This repository contains small JavaScript exercises organized by problem-solving pattern.

## Exercises

### Linear Traversal

- `Palindrome.js` - checks whether a word reads the same forward and backward.
- `ReverseArray.js` - builds a reversed array by traversing from the end.
- `ReverseString.js` - reverses a string by traversing its characters backward.

### Frequency Counter

- `Anagram.js` - compares character counts to determine whether two strings are anagrams.
- `DuplicateCharsinString.js` - finds characters that occur more than once.
- `MaxFrequency.js` - returns the most frequent character and its count.
- `NonRepeating.js` - finds the first character that occurs once.

### Two Pointer

- `Palindrome.js` - checks matching values from both ends of a string or array.
- `Rem_Dup_SortedArr.js` - removes duplicates from a sorted array in place and returns its unique-element count.
- `ReverseArray_StringInPlace.js` - reverses an array in place.
- `Two_Sum(Sorted_Array).js` - finds a target sum in a sorted array, including a helper for unique value pairs.

## Run an exercise

Each file is a standalone script with sample inputs. Run one with Node.js, for example:

```sh
node "JS Coding/Linear Traversal/ReverseString.js"
```
